# Security Policy

This repository is a fork of [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/D4Vinci/Scrapling/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
